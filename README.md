## Kort forklart:

**Klasse** - _Oppskrift_

**Objekt / instans** - _Et faktisk eksemplar laget fra oppskriften_

**Innkapsling** - _Objektet passer på sine egne regler_

**Objektorientering** - _Fordeler ansvar mellom objekter_

**Static** - _Ting som ikke tilhører et bestemt objekt_

**Ny klasse?** - _Når noe har eget ansvar eller egen tilstand_

**Ny metode?** - _Når det bare er en handling/beregning_
